# Sistema_RRHH
Esta aplicación es un Sistema de Recursos Humanos funcional desarrollado utilizando Spring Boot con Java y React. A continuación, se detallan los principales componentes y tecnologías utilizadas:

Full Stack con Spring Boot y React: La aplicación combina la potencia de Spring Boot con Java en el backend con la interfaz de usuario moderna y reactiva de React en el frontend, ofreciendo una experiencia de usuario ágil y eficiente para la gestión de recursos humanos.

Desarrollo de Componentes de Interfaz con React: Se crearon componentes de interfaz de usuario dinámicos y reutilizables utilizando JSX y la librería React, facilitando la construcción de una experiencia de usuario interactiva.

Estilización con Bootstrap: Se integró Bootstrap para proporcionar estilos CSS consistentes y responsivos a la aplicación web, asegurando una presentación visual atractiva y adaptable a diferentes dispositivos.

Comunicación Asíncrona con Servicios Backend: Se implementaron peticiones HTTP asíncronas utilizando AXIOS para la comunicación eficiente entre el frontend de React y los servicios API RESTful del backend.

Desarrollo de Servicios API RESTful con Spring Boot: Se desarrollaron servicios API RESTful robustos utilizando Spring Boot con Java, exponiendo funcionalidades del backend para ser consumidas por el frontend.

Pruebas de Servicios con Postman: Se realizaron pruebas exhaustivas de los servicios API RESTful utilizando Postman, asegurando su correcto funcionamiento y la integridad de las respuestas.

Implementación de la Lógica de Negocio con la Capa de Servicio Spring: Se estructuró la lógica de negocio de la aplicación en una capa de servicio desarrollada con Spring, promoviendo la separación de responsabilidades y la mantenibilidad del código.

Persistencia de Datos con Spring Data JPA y Hibernate: Se gestionó la persistencia de la información del sistema utilizando Spring Data JPA y Hibernate, facilitando la interacción con la base de datos MySql y garantizando una gestión eficiente de los datos de recursos humanos.

Gestión de Datos con Base de Datos MySql: Se configuró y se utilizó una base de datos MySql para el almacenamiento y la gestión de la información del Sistema de Recursos Humanos, asegurando la integridad y disponibilidad de los datos.
